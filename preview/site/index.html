Current MVP

  • Background-worker based annotation flow with cache and settings.
  • Discord and Slack DOM targeting in the content script.
  • Confidence-aware inline chips with 60-second relative-time refresh.

Current limits

  • This is a preview surface, not the extension injected into live chat pages.
  • The local backend is a conservative heuristic parser, not ONNX yet.
  • No bundler or browser packaging flow has been added yet.
