# Privacy

Temporal Lens collects nothing.

The extension is fully local and deterministic:

- No accounts.
- No API keys.
- No AI services.
- No telemetry.
- No analytics.
- No remote servers.
- No network calls.
- No message text or browsing data sent anywhere.

Temporal Lens reads page text only inside your browser so it can detect relative time references and annotate them inline. The original page text is preserved.

Settings and annotation cache data are stored locally in your browser using extension storage and IndexedDB. Cached annotation results expire after 7 days.

Uninstalling the extension removes extension-owned local data according to your browser's extension storage behavior.
